## 2. 产品定位

### 2.1 产品愿景

打造一个现代化、高性能的内容分享平台，让创作者专注于内容创作，让读者轻松获取优质内容。

### 2.2 目标市场

- **内容创作者**：技术博主、行业专家、知识分享者
- **内容消费者**：技术学习者、行业从业者、知识寻求者
- **企业用户**：内部知识库、技术文档平台

### 2.3 核心价值主张

| 价值维度 | 描述 |
|----------|------|
| 创作体验 | 简洁直观的编辑器，支持 Markdown 格式 |
| 阅读体验 | 响应式设计，多端适配，快速加载 |
| 分发效率 | 智能推荐、分类标签、全文搜索 |
| 互动体验 | 评论、点赞、收藏等社交功能 |
| 管理效率 | 完善的后台管理，数据统计分析 |

### 2.4 竞品分析

| 竞品 | 优势 | 劣势 | 差异化策略 |
|------|------|------|------------|
| 掘金 | 社区活跃、流量大 | 内容同质化、审核严格 | 垂直领域、精品内容 |
| CSDN | 历史悠久、内容丰富 | 广告多、体验差 | 简洁界面、无广告 |
| 知乎专栏 | 流量大、变现成熟 | 内容质量参差不齐 | 专业内容、深度文章 |
| Medium | 设计精美、国际化 | 中文内容少、付费墙 | 免费开放、中文优先 |

## 3. 用户分析

### 3.1 用户角色

#### 3.1.1 普通用户 (Visitor/Reader)

**特征**：
- 未注册或已注册但未登录
- 主要行为：浏览文章、搜索内容

**需求**：
- 快速找到感兴趣的内容
- 流畅的阅读体验
- 无需登录即可阅读

#### 3.1.2 注册用户 (Registered User)

**特征**：
- 已完成注册/登录
- 可以互动：评论、点赞、收藏

**需求**：
- 便捷的多方式登录（邮箱、Google、GitHub）
- 个人内容管理（收藏、评论历史）
- 内容订阅与通知

#### 3.1.3 作者 (Author)

**特征**：
- 角色等级：2
- 可以发布文章

**需求**：
- 易用的文章编辑器
- 文章数据统计（阅读量、点赞数）
- 草稿自动保存
- 图片/文件上传

#### 3.1.4 管理员 (Admin)

**特征**：
- 角色等级：3
- 拥有全部管理权限

**需求**：
- 内容审核管理
- 用户管理
- 分类/标签管理
- 数据统计看板

### 3.2 用户画像

#### 画像 A：技术博主张三

| 维度 | 描述 |
|------|------|
| 年龄 | 28 岁 |
| 职业 | 高级开发工程师 |
| 目标 | 分享技术经验，建立个人品牌 |
| 痛点 | 现有平台广告多、排版受限、无法自定义 |
| 期望 | 简洁的编辑器、好的排版、数据统计 |

#### 画像 B：学习者李四

| 维度 | 描述 |
|------|------|
| 年龄 | 24 岁 |
| 职业 | 初级开发工程师 |
| 目标 | 学习技术知识，解决问题 |
| 痛点 | 内容质量参差不齐，搜索效率低 |
| 期望 | 优质内容推荐、全文搜索、收藏功能 |

### 3.3 用户旅程地图

#### 内容消费旅程

```
发现内容 → 浏览列表 → 阅读文章 → 互动 (点赞/评论) → 收藏/分享
   ↓           ↓           ↓            ↓              ↓
 SEO/推荐   分类筛选    目录导航     登录后可评    个人中心
```

#### 内容创作旅程

```
选题构思 → 撰写草稿 → 编辑排版 → 发布审核 → 数据分析
   ↓          ↓          ↓          ↓          ↓
灵感记录   Markdown   图片上传   分类标签   阅读统计
```

3. 记录文件元数据到 files 表
4. 返回文件访问 URL

**输出**

- 文件访问 URL

**异常处理**

- 未登录：返回 401
- 文件不存在：返回"文件上传失败"

**验收标准**

- [ ] 文件元数据记录正确
- [ ] 返回可访问的 URL
